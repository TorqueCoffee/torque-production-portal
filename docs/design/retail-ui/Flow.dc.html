Retail batch, start to finish

Two clicks from the queue: Select (or Select all), then Buy and print. Everything after is packing and one confirm.
Up to 25 orders per batch. UPS Ground only. B2B keeps its own Ship tab and flow unchanged. You pick which orders ship; the portal never selects for you.

Rules the screens enforce

  • UPS Ground only. No rate means no label; never another carrier.
  • Billed lb = ceil(net + carton tare + 0.05), 1 lb minimum.
  • One label per order carton. A reload shows a bought label as bought.
  • No partial shipments. An order with any held line holds whole.
  • Pickup, B2B, cancelled and no-shipping orders never list.
  • Address problems (P.O. box, street line over 35 characters) show in the queue, before buying.
  • Shopify sends the one customer email, at Fulfill only.

Open: the daily routine

Not code. These decide how the Retail tab is used each day.
  • Who runs the batch
  • Cutoff time before the UPS pickup
  • Which printer: Rollo thermal or AirPrint
  • Pickup: real weekly fee, which account, Saturday coverage

After every batch

  • Each label writes a cost row with carton, billed lb and channel.
  • Parcels go to the pickup spot with labels applied.
  • Bad orders go in the 90-day incident log.
  • Monthly: UPS invoice against logged costs; variance over 3% means tare is off.
