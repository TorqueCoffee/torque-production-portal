Needs a fix (shown in the queue)

An order with a P.O. box or a street line over 35 characters lists in a Needs a fix group at the top of the queue, unselectable, with the reason. UPS would refuse it at purchase, so it is caught before buying. Fix it in Shopify and Refresh orders.

Replacement orders

A replacement or comp draft with a 100% discount code lists in the queue with a red REPLACEMENT chip and the reason from the code. It is unselected like every order, and ships like any other.

Void a label

#8322 · 12x8x6 · 3 lb
Bought today, not yet scanned by UPS
Voids the label through Shippo, marks the cost row voided, and returns the order to the queue so it can be selected and bought again.
If Shippo refuses because the label was already scanned, the label stays on and the order is flagged for the incident log.

Held back after buying

If you tap Hold back on a Pack card, the label stays bought and the order stays open. It appears in the queue as bought, not fulfilled, and can be fulfilled in the next batch without buying again. Proposed behavior, to confirm.
